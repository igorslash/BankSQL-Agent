🏦 BankSQL-Agent: Специализированная LLM для банковской аналитики

Инженерный проект по созданию дообученной (Fine-tuned) языковой модели для генерации SQL-запросов на основе естественного языка для банковских систем.
🚀 Основная идея

Базовые модели (GPT/Llama) часто ошибаются в специфических схемах данных и бизнес-логике (например, путают account_id и client_id). Цель проекта: Дообучить компактную модель (Qwen 2.5 1.5B) идеально работать с банковской схемой (Accounts, Transactions, Cards, Clients).
🛠 Технологический стек

    Base Model: Qwen 2.5 1.5B (Unsloth 4-bit quantization)
    Method: LoRA (Low-Rank Adaptation) — r=16, alpha=16
    Frameworks: PyTorch, Hugging Face PEFT, Transformers, TRL
    Inference: FastAPI + Docker (в разработке)

📊 Результаты обучения

    Датасет: 500+ синтетических пар "Инструкция -> SQL", сгенерированных на основе реальной схемы банковских транзакций.
    Оптимизация: Благодаря Unsloth обучение заняло всего 15 минут в Google Colab, потребляя < 8 ГБ VRAM.
    Точность: Модель корректно обрабатывает сложные JOIN-ы и агрегации (GROUP BY/HAVING).

🧩 Схема данных (Context)

Модель обучена понимать связи между:

    clients (сегментация клиентов)
    accounts (балансы, валюты, статусы)
    transactions (движение средств)
    cards (привязка к счетам)

💻 Как запустить (Quick Start)

    Установите зависимости: pip install unsloth
    Загрузите веса адаптера из папки /adapter
    Используйте скрипт inference.py для генерации запросов.
